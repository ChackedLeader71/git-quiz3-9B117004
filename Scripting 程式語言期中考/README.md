# 簡易書籍管理系統 (Book Management System)

這是一個基於 Python 開發的命令列（CLI）書籍管理系統。支援從 JSON 檔案讀取書籍資料，並提供完整的瀏覽、新增、查詢、借閱狀態變更、統計分析與匯出功能。

專案結構

expense-system/
│
├── pkg/
│   └── book_tools.py   # 工具模組（負責讀寫、查詢與顯示書籍）
├── app.py              # 主程式與選單控制
├── books.json          # 原始書籍資料
└── README.md           # 專案說明文件

系統功能特色

顯示全部書籍：條列出所有書籍的編號、書名、作者、價格與借閱狀態。

新增書籍：包含防呆機制（編號不可為空、不可重複、價格須為大於 0 的整數）。

查詢書籍：支援透過書名關鍵字（不分大小寫）快速搜尋。

變更借閱狀態：依書籍編號切換「可借閱」與「已借出」狀態。

顯示最後 3 筆書籍與統計：展示最新加入的三本書，並統計總數、借閱情形、價格合計與平均價格。

匯出書籍資料：將目前的書籍資料匯出為 output.json。

離開系統：安全退出程式。

執行方式

確保已安裝 Python 3 環境。

在命令提示字元（Terminal）中運行主程式：

Bash
python app.py
依照畫面的功能選單提示輸入對應數字操作。
